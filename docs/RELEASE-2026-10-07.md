# DigiLearn enrichment release

This release includes the learning-content enrichment and responsive typography work completed in this session, plus refined catalogue and lesson cards. Lesson cards show their sequence, estimated time, title and first learning objective. Catalogue cards give the practical outcome and project a clear hierarchy. Both keep native links and visible keyboard focus.

Next.js and its matching ESLint configuration were upgraded to 16.4.0 after the release audit identified critical runtime advisories. Compatible dependency updates were also applied. The production dependency audit is clean. Five high-severity audit findings remain in development-only lint dependencies (`braces` and its dependants); the automatic forced remedy proposes downgrading eslint-config-next to 14.2.35 and was not applied.

Release target: the existing DigiLearn Vercel project, project ID `prj_43nfNZMgQ4D5UCBoWpcvuJ1nHjAD`, canonical domain `digilearn-five.vercel.app`. No payment functionality is enabled.

Validation: `npm run verify` passed lint, TypeScript, all 29 tests, content validation, the payment guard and the production build (161 pages). `npm audit --omit=dev` reported zero vulnerabilities. Catalogue, Python, SQL and HTML/CSS course screens passed text-placement checks at 320, 768, 1440 and 2560 pixels. Keyboard focus and a lesson-card navigation were verified in the browser, with no console errors. Screenshot: `docs/qa/lesson-cards-desktop.png`.
