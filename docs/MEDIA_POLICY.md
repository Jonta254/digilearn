# DigiLearn media policy

Every visual must explain something the learner needs to understand. DigiLearn currently uses locally bundled course artwork and 864 internally produced, data-driven technical diagrams. It does not claim third-party lesson photography or copied software screenshots.

## Approved sources

- Wikimedia Commons files after checking the individual file page
- Openverse results only after verifying the original source
- Unsplash and Pexels when the physical environment is educationally relevant
- Self-produced software screenshots from the workflow being taught
- Internally produced, technically reviewed diagrams

For external media, record the creator, original file page, platform, licence, required attribution, review date, local path, intrinsic dimensions, lesson ID and meaningful alternative text. Download and optimize permitted media locally; never hotlink it.

## Rejected sources and uses

- Google Images, Pinterest, random blogs or unclear aggregators
- Watermarked, stretched, low-resolution or uncertain-rights files
- AI-generated instructional photographs
- Fake interfaces, gibberish code or impossible hardware
- Decorative people-with-laptop photography unrelated to the lesson
- Screenshots copied from proprietary learning providers

If a visual does not clarify the lesson, remove it. Selectable code must remain selectable; screenshots may supplement but never replace it.
